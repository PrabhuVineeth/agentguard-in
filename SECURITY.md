# Security Policy

## Supported Versions

AgentGuard-IN is an active research and open-source project. Security updates are applied to the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability, flaw in deterministic state isolation, or unintended execution vector in AgentGuard-IN, please **do not open a public GitHub issue**.

Instead, report the issue via:
1. **GitHub Security Advisory**: Navigate to the **Security** tab of this repository and select **Report a vulnerability**.
2. **Email Disclosure**: Send details to `security@agentguard-in.org` (or maintainers listed in `CITATION.cff`).

### Information to Include:
- Description of the vulnerability or adversarial bypass vector.
- Minimal reproducible test case or trajectory script.
- Proposed remediation or patch, if available.

### Disclosure Timeline:
- We acknowledge receipt within **48 hours**.
- We provide an initial assessment and timeline within **7 business days**.
- Coordinated public disclosure follows after patch validation.
